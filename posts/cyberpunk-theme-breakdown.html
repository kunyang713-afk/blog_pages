霓虹赛博朋克主题实现拆解 ​

这个博客的视觉风格是霓虹赛博朋克。这篇拆解主题是怎么搭起来的，从配色到动画，一步步说清楚。

配色系统 ​

赛博朋克的灵魂是高饱和度的霓虹色，在深色背景上发光。我定了三个主色：

css
:root {
  --neon-cyan: #00f0ff;     /* 青 - 主色 */
  --neon-magenta: #ff00ff;  /* 品红 - 强调 */
  --neon-purple: #b026ff;    /* 紫 - 辅助 */
  --neon-pink: #ff006e;      /* 粉 - 点缀 */
}

背景分四级深色：#050510 最深（页面底）、#0a0a1a 次之（卡片）、#101025 软背景、#181830 静音色。层级感靠透明度叠加，不是死黑。

VitePress 的品牌色变量 --vp-c-brand-1/2/3 映射到青/品红/紫，这样按钮、链接、选中态都自动跟随主题。

字体三件套 ​

css
--vp-font-family-base: 'Rajdhani', sans-serif;      /* 正文 */
--vp-font-family-mono: 'JetBrains Mono', monospace; /* 代码 */
/* 标题硬编码 'Orbitron' */
  • Orbitron：科技感几何标题字体，用在 h1/h2 和按钮。
  • Rajdhani：窄体正文，比无衬线更利落。
  • JetBrains Mono：代码字体，等宽。

走 Google Fonts CDN，<head> 里 preconnect 加速。

动画背景：七层叠加 ​

这是视觉冲击的核心。在 Layout.vue 的 #layout-top 插槽里，从下到上叠了多层：

  1. 数字雨 Canvas（MatrixRain.vue）：最底层，半透明日文假名 + 数字下落。
  2. 平面网格背景（.cyber-grid-bg）：细网格线。
  3. 3D 透视地面网格（.cyber-perspective-grid）：CSS perspective(400px) rotateX(60deg)，配 grid-move 动画向前滚动。
  4. 扫描线（.scanlines-overlay）：CRT 显示器横纹。
  5. 光斑（.glow-orb）：两个青色/品红模糊光球，filter: blur(80px) 缓慢漂浮。
  6. 粒子 Canvas（ParticleField.vue）：飘动的小点。
  7. HUD 四角装饰（.hud-corner）：屏幕四角的科技感框线，带闪烁动画。

每层都 pointer-events: none，不挡交互。

Canvas 组件的 SSR 处理 ​

VitePress 构建时 SSR 预渲染，Canvas 组件直接访问 window 会崩。我的处理套路：

vue
<script setup>
import { onMounted, onBeforeUnmount, ref } from 'vue'

const canvas = ref(null)

onMounted(() => {
  if (typeof window === 'undefined') return  // 守卫
  // 这里才能安全用 window/document
  window.addEventListener('resize', handler)
})

onBeforeUnmount(() => {
  if (typeof window === 'undefined') return
  window.removeEventListener('resize', handler)
  cancelAnimationFrame(rafId)
})
</script>

三件套：onMounted 启动 + typeof window 守卫 + onBeforeUnmount 清理监听和 rafId。缺一不可，否则内存泄漏或构建失败。

鼠标跟随光晕 ​

一个 220px 的径向渐变圆，mix-blend-mode: screen 跟随鼠标。用 lerp(0.15) 缓动让移动丝滑，不是硬贴。移动端用 @media (hover: none) 隐藏。

Features 卡片流光边框 ​

这是最花哨的一处。用 @property 注册一个 <angle> 自定义属性，配合 conic-gradient 做旋转流光：

css
@property --angle {
  syntax: '<angle>';
  initial-value: 0deg;
}

.VPFeature::before {
  background: conic-gradient(from var(--angle), /* ... */);
  animation: border-rotate 4s linear infinite;
}

@keyframes border-rotate {
  to { --angle: 360deg; }
}

hover 时伪元素 opacity: 1 显现，旋转的霓虹边框就亮起来。

尊重用户偏好 ​

最后一层是 @media (prefers-reduced-motion: reduce)，把所有动画 animation: none。前庭功能障碍的用户会感谢你。

最后 ​

主题不难，难的是耐心调参。每个颜色值、每个动画时长都是反复试出来的。赛博朋克风容易做过头变成「眼花」，关键是克制：背景层透明度压低（0.22 / 0.55），让内容浮在上面，动画是点缀不是主角。
